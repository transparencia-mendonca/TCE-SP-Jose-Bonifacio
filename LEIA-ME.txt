TCESP José Bonifácio — v0.9.18-JB
BASE HISTÓRICA PERMANENTE

Objetivo desta atualização
--------------------------
Perenizar no próprio repositório a base que estava apenas no IndexedDB do navegador.
A atualização da interface deixa de depender de recarregar os exercícios pela API do TCESP.

Como funciona
-------------
1. O banco local continua sendo IndexedDB com o mesmo nome usado na v0.9.17-JB:
   tcesp-jose-bonifacio-v6
2. Se o navegador já possui dados. a nova versão PRESERVA integralmente esse banco e NÃO baixa
   novamente os arquivos históricos.
3. Em um navegador novo. sem IndexedDB. o painel lê baseline-manifest.json e restaura
   automaticamente a fotografia histórica armazenada nos arquivos data-AAAA.json.
4. O botão "Restaurar base" passa a restaurar essa fotografia permanente do repositório.
5. Atualizações mensais pela API continuam sendo gravadas somente no IndexedDB local.
6. Futuras versões de interface não devem trocar DBN nem apagar o IndexedDB.

ATENÇÃO SOBRE A COBERTURA DO BACKUP
-----------------------------------
Esta versão não inventa nem busca dados ausentes: ela pereniza exatamente o conteúdo do backup.
